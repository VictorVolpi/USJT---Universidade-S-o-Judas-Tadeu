### 🟢 Atividade 1 → Criação de uma rede com Roteadores → HTTP → DNS.

⏺︎ Roteador.<br>
  ○ Será o gateway entre sub-redes.<br>
  ○ Configuração de interfaces com IPs nas redes correspondentes.<br>
  
⏺︎ Servidor DNS / HTTP.<br>
  ○ Servidor com IP fixo.<br>
  ○ Serviços habilitados: DNS e HTTP.<br>
  
⏺︎ Papel do Gerente de Redes na proteção da informação.<br>
  ○ IPs na mesma rede.<br>
  ○ Configurar gateway padrão apontando para o roteador.<br>
  ○ DNS apontando para o servidor DNS.<br>
  
⏺︎ Confira meu projeto no GitHub: [Criação de uma rede com Roteadores → HTTP → DNS.](https://github.com/VictorVolpi/USJT---Universidade-S-o-Judas-Tadeu/blob/main/Roteador%20-%20HTTP%20-%20DNS.zip)<br>

### 🟢 Atividade 2 → Switch e Hub.

⏺︎ Hub.<br>

  ○ Transmite os pacotes para todas as portas (broadcast), menos eficiente, mais colisões em redes maiores.<br>
  
⏺︎ Switch.<br>

  ○ Envia pacotes apenas para a porta de destino correta (unicast), reduz colisões e melhora desempenho.<br>
  
⏺︎ Confira meu projeto no GitHub: [Switch e Hub.](https://github.com/VictorVolpi/USJT---Universidade-S-o-Judas-Tadeu/blob/main/Switch%20e%20Hub.zip)<br>

### 🟢 Atividade 3 → Criação de uma rede com Roteadores → SMTP → Switch.

⏺︎ Roteador.<br>
  ○ Encaminha pacotes entre diferentes redes (sub-redes) ou entre LAN e Internet.<br>
  ○ Configuração com interfaces com IP, roteamento estático.<br>
  
⏺︎ Switch.<br>
  ○ Protocolo usado para envio de e-mails entre clientes e servidores ou entre servidores<br>
  
⏺︎ SMTP.<br>
  ○ Conecta dispositivos dentro da mesma rede (LAN).<br>
  ○ Encaminha pacotes apenas para o destino correto, reduzindo colisões.<br>
  
⏺︎ PCs.<br>
  ○ Configurados com IP, máscara de sub-rede, gateway (IP do roteador).<br>
  ○ Configuração do SMTP para envio de emails.<br>
  
⏺︎ Confira meu projeto no GitHub: [Criação de uma rede com Roteadores → SMTP → Switch.](https://github.com/VictorVolpi/USJT---Universidade-S-o-Judas-Tadeu/blob/main/SMTP%20-%20SWITCH%20-%20ROUTER.zip)<br>

### 🟢 Atividade 5 → Criação de um Ambiente completo.

⏺︎ Estrutura da Topologia em Estrela.<br>
  ○ Os Roteador Centro da topologia, conecta toda a rede e fornece roteamento.<br>
  ○ Os Switches Distribuem a rede para PCs e servidores.<br>
  ○ Os Servidores Podem estar conectados diretamente a um switch ou ao roteador, dependendo da criticidade.<br>
  
⏺︎ Endereçamento IP sugerido.<br>

⏺︎ Conexão e Serviços.<br>
  ○ Conectar cada switch ao roteador com cabo Ethernet.<br>
  ○ Conectar PCs e servidores aos switches.<br>
  ○ Configurar DNS e HTTP no servidor para testes internos.<br>
  ○ Configurar SMTP no mesmo servidor para envio de e-mails de teste..<br>
